# Themes

These JSON files are bundled with the app and appear in Settings, Theme. They also serve as examples:
copy one, change it, and you have your own.

| File | Shows off |
|---|---|
| `chattunes-dark.json`, `chattunes-light.json` | The defaults |
| `amoled.json` | Custom surface colors, sharp corners, solid covers |
| `sunset.json` | Player at the top, round covers, flat player |
| `terminal.json` | Square corners, dense list, numbered rows, rail left and player panel right on desktop |
| `paper.json` | Light, large rounded covers, side-by-side Now Playing |

The format is described in [../docs/THEMING.md](../docs/THEMING.md). Community themes go in
[community/](community).
